# TypeSafe jev — канал типізованих рішень

Ключ доданий 21.09.2026 за вказівкою Павла. Лежить у `~/.secrets/typesafe.env`
(права 600, поза периметром бекапу, як і решта ключів). У вікі, в git і в
жодну допоміжну модель ключ не потрапляє. Ключ вставлявся в чат хмарної сесії,
тому після першого прогону його треба перевипустити в консолі, старий відкликати.

## Що це

Не чат-модель. На вхід іде стан (текст або JSON) і набір закритих питань трьох
типів: Noul (так/ні), Choice (один з N), Score (упорядкована шкала). На вихід
розподіл імовірностей по варіантах і confidence; вільного тексту немає, тому
модель не може ні процитувати, ні вигадати цитату. Реєстрація самостійна на
console.typesafe.ai, стартовий кредит $5.

| Параметр | Значення |
|---|---|
| Модель | `jev-1.13.0`; алiас `jev-latest` не використовувати, він дрейфує |
| Ціна | $0,042 за 1M вхідних токенів, вихід безкоштовно |
| Контекст | 64k на запит, 32k на стан плюс найдовше питання; через Cloudflare лише 32k |
| Ліміти | 250k токенів/с, 1200 запитів/хв, змінюються |
| Затримка | заявлено 70–500 мс; незалежний замір близько 1,4 с |
| Точність | на власних евалах вендора 68 % згоди з консенсусом двох фронтир-моделей; на українському не заміряно ніким |
| Дані | не навчається на запитах; ZDR на запит; DPA як процесор за GDPR |

## Роль у нашому контурі

Канал стоїть поруч із Groq, Mistral, OpenRouter, GLM, Muse і Cloudflare як
дешевий помічник, але з іншим призначенням: він не пише і не пояснює, а
відповідає на закриті питання. Дві ролі:

1. **Учитель слабкої розмітки** для голів `vlc_ua.judge` там, де еталона мало:
   мітки jev ідуть у gold зі `source="typesafe"`, розбіжності з бейзлайном
   читаються очима, і лише після цього на них навчається власна голова.
2. **Точка порівняння** на еталоні: та сама команда, той самий звіт, що і для
   keyword-бейзлайну та власної голови.

Куди не ставити: у робочий шлях пошуку, у верифікацію цитат, у синтез, у
розрахунок строків. Це «ознака, не вердикт», як і решта дешевих каналів.

## Як викликати

```bash
set -a; . ~/.secrets/typesafe.env; set +a
cd /srv/work/judge
vlc-judge run --backend typesafe --model jev-1.13.0 --task attribution.task.json \
  --gold attribution.jsonl --limit 500 --out runs/jev-attribution.json --cache .judge-cache-jev
vlc-judge report runs/jev-attribution.json --task attribution.task.json \
  --gold attribution.jsonl --baseline runs/kw-attribution.json > reports/jev-attribution.json
```

Бекенд `typesafe` у пакеті `vlc_ua.judge` (репозиторій `vlc-ua`, гілка
`claude/fervent-shannon-lz9k6j`, файл `backends/external.py`) шле заголовок
`X-Zero-Data-Retention: true`; назву заголовка в документації не звірено, тому
ZDR додатково вмикати в налаштуваннях консолі.

## Межі даних

- Публічні тексти ЄДРСР: вільно.
- Матеріали клієнтських справ: лише після оформлення DPA; до того не гнати.
- Коди доступу: ніколи.

## Cloudflare

`typesafe/jev` є в каталозі Cloudflare AI, маршрут той самий `/ai/run`, що і в
`cf-subagents`. Але сторонні моделі не входять у безкоштовні нейрони: потрібен
або ключ TypeSafe у BYOK шлюзу, або поповнені кредити з платіжним методом.
Станом на 21.09.2026 платіжного методу на акаунті немає, тож маршрут не
ввімкнений; прямий виклик через ключ простіший.

## Стан
